# NOVA/GEN Visual System

## Brand personality

Scientific
Precise
Experimental
Premium
Futuristic

## Composition

Desktop:
- max content width: 1440px
- outer padding: 48–72px
- oversized editorial headings
- strong negative space
- scientific visuals may break container

Mobile:
- 20px side padding
- simplified WebGL
- typography scales significantly
- no desktop layout merely stacked vertically

## Typography

Display:
large grotesk / editorial sans

Metadata:
IBM Plex Mono

Metadata treatment:
uppercase
11–12px
0.08–0.14em tracking

## Surface treatment

Do not use generic glass cards.

Preferred:
- black/green surfaces
- extremely thin borders
- subtle biological noise
- occasional pale section
- irregular image masks
